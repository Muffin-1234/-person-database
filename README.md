# Person Database Analysis

## Project Overview

This project involves exploring and analysing
person database using PostgreSQL.

The dataset contains information about individuals,
including their names, email addresses, gender,
dates of birth and countries.

## Tools Used

- PostgreSQL
- SQL
- GitHub

## Dataset Description

The dataset contains the following columns:

- First Name
- Last Name
- Email
- Gender
- Date of Birth
- Country

## Project Objectives

1. Explore the structure of the database.
2. Examine the distribution of individuals by country.
3. Analyse gender distribution.
4. Identify missing email addresses.
5. Examine age distribution.
6. Identify data quality issues.
7. Generate meaningful insights from the dataset.

## SQL Concepts

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT
- AVG
- CASE WHEN
- NULL Handling
- Aggregate Functions

## Project Structure

- Dataset: Original SQL dataset.
- SQL: Analytical SQL queries.
- Results: Findings and conclusions.

This project demonstrates the use of PostgreSQL
for database exploration, data analysis and
extracting meaningful insights from structured data.
